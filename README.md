# CollabDraw

This is a real-time collaborative drawing app.

## How to Run

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Start the server:**
    ```bash
    npm start
    ```
    This will start the server on `http://localhost:3000`.

3.  **Test Multi-User Collaboration:**
    Open `http://localhost:3000` in multiple browser tabs or windows. Drawings, cursors, and undo/redo actions will be synchronized in real-time across all clients.
